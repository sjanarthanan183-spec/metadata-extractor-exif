Metadata Extractor

1. Project Title

Metadata Extractor Using Python

2. Aim

To extract and display basic information from a text file using Python.

3. Description

The Metadata Extractor is a simple Python program that reads a ".txt" file and displays its basic details, such as file name, file size, file extension, and word count.

4. Features

- Extracts the file name.
- Displays the file extension.
- Calculates the file size.
- Counts the number of words.
- Displays the extracted information clearly.

5. Requirements

- Python 3
- Any text editor, such as Notepad or VS Code
- A ".txt" file for testing

6. How to Run

1. Save the Python program as "metadata_extractor.py".
2. Create a text file for testing.
3. Open Command Prompt or the VS Code terminal.
4. Run the following command:

python metadata_extractor.py

7. Sample Output

===== METADATA EXTRACTOR =====

File Name: sample.txt
File Extension: .txt
File Size: 85 bytes
Word Count: 12

Metadata extraction completed successfully!

Note: The output values depend on the input file.

8. Applications

- Basic file information analysis
- Text file inspection
- Learning Python file handling

9. Conclusion

The Metadata Extractor demonstrates how Python can be used to read a text file and extract basic file information efficiently.
